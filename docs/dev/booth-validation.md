# 공룡 증시 검증 기록

구현 작업 공간: codex/dinosaur-booth. 승인 설계는 docs/superpowers/specs/2026-10-27-dinosaur-booth-design.md를 따른다.

현재 확인:
- 기존 프론트엔드와 신규 UI 테스트 158개 통과.
- PostgreSQL 16에서 부스 테스트 32개 통과. 동시 24개 매수 요청의 잔고 초과 방지와 동일 요청 중복 체결 방지 포함.
- Alembic 0011 → 0012 upgrade/check, 0012 → 0011 → 0012 왕복/check 통과.
- 기존 참가자 sentinel 행과 현금 1,000,000원이 마이그레이션 전후 보존됨.
- 초기 백엔드 기준선의 날짜 의존 메일 테스트는 행사 기간 내 고정 시계를 주입하도록 수정.

추가 기록 예정: 전체 회귀 최종 결과, 시뮬레이션 분포, 80명 조회 부하, 브라우저 화면 확인, 독립 검토.

- 백엔드 전체 SQLite 회귀: 402 통과,19 건너뜀. PostgreSQL 전체: 420 통과,1 건너뜀(연결 풀 전용 환경 테스트). 이후 사건 일정 추출의 추가 검증은 7 통과.
- 프론트엔드 프로덕션 빌드·타입 검사 통과. 기존 앱은 별도 청크로 지연 로딩하며 기본 JS는 gzip 약119kB.
- PostgreSQL/PgBouncer/backend/Caddy frontend/pgAdmin 전체 Compose 서비스 healthy. HTTP로 참가·주식·중복 요청·펀드·섹터 사건·마감·시상 확정·다음 장 초기화·SPA/PNG/404 경로를 확인.
- 단일 로컬 프로세스/PostgreSQL,300개 가격 이력,80명,5회 동시 조회(총400건),80건 주식 주문: 오류0,응답 약136kB,조회 p50 411.71ms,p95 555.22ms,최대630.05ms;주문 p95 187.71ms. 인터넷·현장 Wi-Fi 환경의 지연을 보장하는 수치가 아니다.
- 실제 브라우저에서 닉네임 참가·펀드 100,000원 매수·99.806375좌 전량 환매와 현금/거래 내역 확인. 1440px 데스크톱/390px 모바일 레이아웃 확인.
